# CustomGit
Это проект, **целью** которого является создания системы контроля версий. Причём как со стороны **клиента**, так и со стороны **сервера**.
Основными задачами проекта являются:
### Создание клиента, который будет отправлять такие запросы на сервер как:
	1. Создание репозитория
	2. Создание веток
	3. Управление изменениями этих веток
	4. Слияние веток
	5. Клонирование репозитория
	6. И др.
### Создание сервера, который будет обрабатывать запросы клиента и выполнять следующие задачи:
	1. Обработка запросов пользователя
	2. Сохранение репозиториев в базе данных сервера
	3. Сохранение веток для каждого из репозиториев
	4. Загрузка этих данных
	5. Управление данными в базе данных
	6. Обратная связь клиенту
